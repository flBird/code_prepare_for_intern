# 有序链表去重（相邻重复，保留首份）

> 整理时间：2026-09-04 20:06:38
> 对应代码：`dropduplicate(self)` —— 基于带头结点单链表

## 1. 功能定位

删除有序单链表中**相邻的重复结点**，每个值的重复组**只保留第一个**，其余跳过。
> 等价于 LeetCode 83「Remove Duplicates from Sorted List」。
> **前提：链表必须已排序**。只有有序时相同值才相邻；若无序，本写法只能去掉"恰好相邻"的重复，无法全局去重。

示例：`1→1→2→3→3` → `1→2→3`（保留每组首份）。

注意与 LeetCode 82 区分：82 是把"出现过重复的值整组删光（连第一个也删）"；本代码是 83，留一份。

## 2. 代码

```python
def dropduplicate(self):
    prev = self.dummyhead
    cur = prev.next
    while cur:
        prev.next = cur        # (A) 把已保留链的尾接到 cur
        prev = cur             # (B) prev 前进到 cur

        if cur.next and cur.val == cur.next.val:   # (C) 发现相邻重复
            dropnum = cur.val
            while cur and cur.val == dropnum:      # (D) 越过所有同值副本
                cur = cur.next
        else:
            cur = cur.next       # 普通前进
    prev.next = None          # 收尾截断
```

## 3. 思路拆解（双指针）

- `prev`：已保留链表的**最后一个结点**（初始指向 dummyhead，即"已保留部分的尾巴"）。
- `cur`：当前遍历指针。
- 每轮循环开头先做 `(A)(B)`：`prev.next = cur` 再 `prev = cur`。
  含义是"先把已保留链的尾巴接到当前结点，再把 prev 前移一步"。这一步保证已保留部分始终不断链。

### 两种情况

**(C) 命中相邻重复**（cur 与 cur.next 同值）：
- 记下 `dropnum = cur.val`（要丢弃的值）。
- 内层 `(D)` 把 `cur` 一直后移，越过所有等于 `dropnum` 的结点（**包括当前这份 cur**）。
- 此时 `prev` 仍然停在"该值的第一份"上，而 `cur` 已到了该组之后。

**(否则)** 普通前进：`cur = cur.next`，prev 也已在 (B) 前进到 cur，正常。

### 为什么能"保留首份、删掉副本"？

关键在顺序：(B) 先把 `prev` 指到了该值的第一份，然后 (D) 才把 `cur` 推过"后续副本"。
下一轮循环开头 `(A)` 执行 `prev.next = cur` —— 此时 `prev` 是第一份、`cur` 是组后结点，
于是第一份被直接接到组后结点上，**中间的副本全部被跳过**。第一份因此保留，副本被删。

### 收尾 `prev.next = None`

`prev` 停在最后一个保留结点。循环结束后把它 `next` 置空，截断后面可能残留的越界结点，
确保新链表正确结束（即使原链表最后一段是重复组也安全）。

## 4. 复杂度

- 时间：`O(n)`，cur 每结点最多访问一次（内层 while 总计也只把每个结点跳一次），一趟扫描。
- 空间：`O(1)`，只用了 prev / cur / dropnum 几个指针变量，原地修改。

## 5. 易错与注意点

1. **必须有序**：无序链表此写法不成立（只能去"相邻"重复）。
2. **(A) `prev.next = cur` 不能省**：它负责把上一组保留下来的尾连到当前 cur，缺了会断链（本代码把它放在循环顶部统一处理，比"只在 else 分支连"更简洁）。
3. 与 LeetCode 82 混淆：想"整组删光（含首份）"时，应把 (B) 改为在"确认无重复"时才让 prev 前进；本代码只要进入 (C) 分支就不前进 prev，等于留首份 —— 这是 83 而非 82。
4. `dummyhead` 的存在让"删除/跳过首元结点"无需特殊处理，结果统一从 `dummyhead.next` 取。
5. 极端情况：
   - 空表：cur 为 None，循环不进，prev.next=None，安全。
   - 全相同 `1→1→1` → `1`（保留一份）。
   - 严格递增 `1→2→3` → 原样保留。

## 6. 一句话总结

用 prev / cur 双指针一趟扫描：每遇到"当前结点与下一个同值"就记下该值、把 cur 越过整组副本；
由于 prev 在越过之前已指向首份，下一轮 `prev.next = cur` 自然只删副本、留首份；最后 `prev.next=None` 收尾。
