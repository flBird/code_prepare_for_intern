# 最长公共子序列（LCS）一维滚动数组 DP

> 整理时间：2026-09-05 11:10:38
> 对应代码：maxCommon(s1, s2) —— 空间 O(n) 的滚动数组写法
> 题源等价：LeetCode 1143「Longest Common Subsequence」

## 1. 问题定位：子序列 ≠ 子串

- 子串：连续的一段。
- 子序列：可以不连续，但相对顺序要保持。

题目要的是最长公共**子序列**，所以不能用滑动窗口/双指针贪心，而要用 DP（或高级数据结构），因为"跳过某些字符"的取舍必须用状态记录。

## 2. 二维 DP 定义（先理解原始版）

`dp[i][j]` = `s1` 的前 i 个字符 与 `s2` 的前 j 个字符 的 LCS 长度。

转移（经典）：
- 若 `s1[i-1] == s2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`（这两个字符都能用上）。
- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（丢弃 s1 末字符 或 丢弃 s2 末字符，取较优）。

边界：`dp[0][*] = dp[*][0] = 0`。

注意：每一行 `dp[i][*]` 只依赖上一行 `dp[i-1][*]` 和本行已经算出来的 `dp[i][j-1]`，**不依赖更上面的行**。这就是能"压成一维"的前提。

## 3. 一维滚动数组：关键在 pre / nxtpre

原始二维里，算 `dp[i][j]` 需要三个值：
- `dp[i-1][j-1]`（左上，斜上）—— 额外加 1 用
- `dp[i-1][j]`（正上）—— 来自上一行同列
- `dp[i][j-1]`（左）—— 本行已算

若只保留一维 `dp[j]`（表示当前的第 i 行第 j 列），遍历到 j 时：
- `dp[j]`：在一维数组里，它此刻存的是**上一行**的 `dp[i-1][j]`（正上）。
- `dp[j-1]`：本行 j-1 已经算过，是 `dp[i][j-1]`（左）。
- `dp[i-1][j-1]`（左上）：**最难保**——因为一维数组在算完 j-1 之后，`dp[j-1]` 已经被覆写成本行的值，原始的"上一行 j-1"丢了。

→ 解决办法：用一个变量 `pre` 在每轮循环开头**手动保存"上一行 j-1"**。

### 代码逐行解析

```python
m, n = len(s1), len(s2)
if m == 0 or n == 0:
    return 0
dp = [0 for _ in range(n + 1)]        # 一维，长度 n+1，初始全 0（即第 0 行的状态）
for i in range(1, m + 1):
    pre = 0                            # 每个新 i 开始时，左上角 dp[i-1][0] = 0
    for j in range(1, n + 1):
        nxtpre = dp[j]                 # 先把当前 dp[j] 存起来（它是下一轮的"左上"）
        dp[j] = max(dp[j], dp[j-1],
                    pre + 1 if s1[i-1] == s2[j-1] else 0)
        pre = nxtpre                   # 更新 pre 为本轮的"上一行 j"，供下一轮当左上用
return dp[n]
```

### pre / nxtpre 的角色（重点）

- `pre`：**保存 `dp[i-1][j-1]`（左上）**。它在进入内层循环时被初始化为 0（对应 j=0 时左上=0），之后每轮被更新为"上一轮处理完的 `dp[j]`"，也就是上一行同一列的旧值——而那个旧值，正是下一轮要用的左上。
- `nxtpre`：**在覆盖 `dp[j]` 之前，先把它的旧值（上一行 `dp[i-1][j]`）备份出来**，赋给下一轮的 `pre`。也就是说 `nxtpre` 是"pre 的传送带"：本轮的 `dp[j]` 旧值 → 下一轮的 `pre`。
- 时序非常关键：必须先 `nxtpre = dp[j]`（备份），再 `dp[j] = ...`（覆盖），最后 `pre = nxtpre`（交接）。顺序反了就会用到已被覆盖的值。

一句话记忆：**`dp[j]`（更新前）= 正上 = 下一轮的左上，所以用 nxtpre 暂存、再传给 pre**。

### 为什么不写成 max(dp[j], dp[j-1], pre+1) 也行？

其实 `s1[i-1] != s2[j-1]` 时，`pre+1` 不应参与，所以代码用 `pre + 1 if 相等 else 0`，等价于二维版的"不相等就取 max(上, 左)"，而 `pre+1` 只在相等时才是正确增量。写成 `max(dp[j], dp[j-1], pre)` 也行（pre 已在 dp[j] 或 dp[j-1] 里），但 `pre+1 if 相等` 更直观对应"左上 +1"。

## 4. 复杂度

- 时间：O(m * n)，两层循环。
- 空间：O(n)（一维数组），比二维 O(m*n) 省一个数量级；若 n 更小，让 s2 当较短串更优（当前代码固定 dp 长度 = n+1）。

## 5. 示例

s1 = "abcde", s2 = "ace" → LCS = "ace"，长度 3。
逐行滚动后 `dp[n]` 最终为 3。

s1 = "abc", s2 = "abc" → 3。
s1 = "abc", s2 = "def" → 0（无公共）。

## 6. 易错点

1. pre 的初值必须是 0（对应 dp[i-1][0] = 0），不能遗漏，否则第一列左上错。
2. nxtpre 必须在 dp[j] 被覆盖"之前"赋值，顺序不能反。
3. 下标是 `s1[i-1]` / `s2[j-1]`（i,j 从 1 开始，字符串从 0 开始），越界常见坑。
4. 子序列问题才能这么 DP；子串（连续）要用 `dp[j] = pre+1 if 相等 else 0`（不能取 max，断了就归零）。本代码是子序列版。
5. 外层 try/except 包裹 input() 是为了多组用例在文件结束/异常时自然退出（ACM 模式）。
