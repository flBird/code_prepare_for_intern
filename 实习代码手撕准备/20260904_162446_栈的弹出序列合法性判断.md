# 栈的弹出序列合法性判断

> 整理时间：2026-09-04 16:24:46
> 题源等价：剑指 Offer 31「栈的压入、弹出序列」 / LeetCode 946「Validate Stack Sequences」

## 1. 问题本质

给定 `1 ~ N` 共 N 个元素，按 `1, 2, ..., N` 的顺序依次**入栈**（每个元素只能入栈一次，且入栈顺序固定），在任意时刻都可以**出栈**。
问：给定的出栈序列 `out_series` 是否可能由某一个合法的「入栈 / 出栈」操作序列产生？

通俗类比：一列火车 `1..N` 顺序驶入一个死胡同（栈），从胡同口随时可以放车头出去，最终能否排成目标顺序。

## 2. 核心思路：贪心模拟

因为入栈顺序已经固定（永远是 1→N），我们只需**忠实模拟**整个过程，看能否把目标序列「拼」出来：

- 用一个「出栈指针」`j` 指向 `out_series` 中下一个应当匹配的输出元素（初始 0）；
- 用一个「入栈指针」`i` 依次把 `1..N` 压入栈；
- **每压入一个元素后**，只要「栈顶 == out_series[j]」，就持续把栈顶弹出并 `j++`（能匹配就匹配）；
- 当 `1..N` 全部入栈结束后，若栈为空，说明所有元素都按目标顺序弹出了 → `Yes`；否则 `No`。

### 为什么「能弹就弹」是对的？（正确性）

栈顶元素是当前**最容易**弹出的元素；如果它正好等于 `out_series[j]`，就必须**现在**弹——
因为再往栈里压后面的元素只会让它被埋得更深，之后更难（甚至不可能）再匹配到 `out_series[j]`。
所以「只要栈顶匹配就弹出」既是必要的也是充分的，这就是贪心策略的正确性来源。

## 3. 复杂度

- 时间复杂度：`O(N)`。每个元素最多入栈一次、出栈一次，每个元素被操作常数次。
- 空间复杂度：`O(N)`。栈最多同时容纳 N 个元素，外加两个数组。

## 4. 代码逐行解析

```python
while 1:
    try:
        N = int(input())            # 读入元素个数
        if N == 0:                  # 读到 0 结束（多组用例的终止条件）
            break
        out_series = list(map(int, input().split()))   # 目标出栈序列
        in_series = [(i + 1) for i in range(N)]        # 固定入栈顺序 1..N
        j = 0                       # 出栈指针：下一个要匹配的目标元素下标
        stack = []                  # 模拟栈
        for i in range(N):
            stack.append(in_series[i])                  # 把当前元素压栈
            while j < N and len(stack) > 0 and stack[-1] == out_series[j]:
                stack.pop()        # 栈顶匹配目标，出栈
                j += 1             # 目标指针后移
        if len(stack) == 0:        # 全部元素都能按目标顺序弹出
            print('Yes')
        else:
            print('No')
    except:
        break                      # 输入结束 / 异常时退出
```

要点：
- `in_series[i]` 其实就是 `i+1`，可以简化写成 `stack.append(i + 1)`。
- `while` 的循环条件 `j < N` 与 `len(stack) > 0` 是为了越界与空栈保护。
- 外层用 `try/except` 包裹，便于在文件输入或交互结束时自然退出。

## 5. 示例

输入：
```
5
3 2 1 5 4
0
```
过程：压 1,2,3 → 栈顶 3 匹配 → 弹 3；栈顶 2 匹配 → 弹 2；栈顶 1 匹配 → 弹 1；
压 4,5 → 栈顶 5 匹配 → 弹 5；栈顶 4 匹配 → 弹 4。栈空 → `Yes`。

输入：
```
5
3 1 2 4 5
0
```
压 1,2,3 → 弹 3；栈顶是 2，但目标是 1，无法弹出 → 继续压 4,5，始终卡住，栈非空 → `No`。

## 6. 易错点

- 入栈顺序固定为 `1..N`，不要把 `in_series` 当成输入的一部分。
- 必须在「每压入一个元素之后」就立即尝试连续弹出，而不是全部压完再弹（否则可能错过合法序列）。
- 多组用例记得用 `N == 0` 或异常正确终止循环。
