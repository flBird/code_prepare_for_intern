# 最长公共子串（连续）—— 与 LCS 的 dp[i][j] 含义对比

> 整理时间：2026-09-05 11:16:51
> 对应代码：longestCommonSubstring(s1, s2) —— 一维滚动 DP
> 题源等价：LeetCode 718「Maximum Length of Repeated Subarray」

## 0. 最重要的区别先说：两个问题的 dp[i][j] 含义不同！

这是子序列（LCS）和子串最容易混、也最关键的一点：

| | LCS（最长公共子序列，不连续） | 最长公共子串（连续） |
|---|---|---|
| dp[i][j] 含义 | s1 前 i 个 和 s2 前 j 个 的**最长公共子序列长度**（不要求以谁结尾） | 以 s1[i-1] 和 s2[j-1] **为结尾** 的公共子串长度 |
| 答案来源 | 整张表的全局最大 = 最后一行末尾 dp[m][n] | 所有格子里的全局最大（必须边走边记 maxlen） |
| 字符不等时 | 保留之前最优：max(上, 左) | 连续性断：直接归零 dp[i][j] = 0 |
| 字符相等时 | dp[i-1][j-1] + 1（但仍取 max 兜底） | dp[i-1][j-1] + 1（唯一值，延长） |

一句话记忆：
- LCS 的 dp[i][j] 是"到 (i,j) 为止的**前缀里**能凑出的最长"（更宽松，不锚定结尾）。
- 子串的 dp[i][j] 是"**恰好以 (i,j) 结尾**的最长"（更严格，锚定结尾）。

正因为"子串锚定结尾"，所以一旦字符不等就归零；也正因为它只关心结尾，答案可能落在任意格子，不能只看 dp[m][n]。

## 1. 子串的二维 DP 定义

`dp[i][j]` = 以 `s1[i-1]` 和 `s2[j-1]` 为结尾的公共子串长度。

转移：
- 若 `s1[i-1] == s2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`（顺着左上延长 1）
- 否则：`dp[i][j] = 0`（连续性断，从 0 重来）

只依赖**左上** `dp[i-1][j-1]`，不依赖正上/左——比 LCS 还简单。

## 2. 一维滚动数组写法

和 LCS 的滚动骨架一模一样（pre/nxtpre 同构），只改"格子更新"并多维护 maxlen：

```python
def longestCommonSubstring(s1, s2):
    m, n = len(s1), len(s2)
    if m == 0 or n == 0:
        return 0
    dp = [0] * (n + 1)
    maxlen = 0
    for i in range(1, m + 1):
        pre = 0                      # 保存 dp[i-1][j-1]（左上）
        for j in range(1, n + 1):
            nxtpre = dp[j]           # 覆盖前先备份，作为下一轮的左上
            if s1[i-1] == s2[j-1]:
                dp[j] = pre + 1      # 相等：延续左上 +1
            else:
                dp[j] = 0            # 不等：连续断，归零
            pre = nxtpre
            if dp[j] > maxlen:
                maxlen = dp[j]       # 全局最长可能在任意格子，边走边记
    return maxlen
```

### pre / nxtpre 的角色（与 LCS 完全一致）

- `pre`：保存 `dp[i-1][j-1]`（左上）—— 子串版里它**就是唯一被读取的旧状态**。
- `nxtpre`：在覆盖 `dp[j]` 之前先备份它的旧值（上一行 `dp[i-1][j]`），赋给下一轮的 `pre`，是"pre 的传送带"。
- 时序：先 `nxtpre = dp[j]`（备份）→ 再 `dp[j] = ...`（覆盖）→ 最后 `pre = nxtpre`（交接）。

子串版相比 LCS，更新时**只用 pre**，连 `dp[j]`、`dp[j-1]` 都不需要，pre 反而更核心。

## 3. 与 LCS 的三点关键差异（对照）

1. 字符不等时：LCS 取 `max(上, 左, ...)` 保留之前最优；子串直接 `= 0` 归零。
2. 字符相等时：LCS 是 `pre + 1`（但仍被 max 包着兜底）；子串是 `pre + 1`（唯一值）。
3. 最终答案：LCS `return dp[n]`（末行末列即全局最大）；子串 `return maxlen`（必须全程跟踪，dp[n] 未必最大）。

## 4. 示例

- `s1 = "abcde"`, `s2 = "aebc"`：
  - LCS = 3（`abc` 或 `abe`，不连续也能拼）
  - 子串 = 1（只有单个 a/b/c 连续匹配，没有长度 ≥2 的公共连续串）
- `s1 = "ababc"`, `s2 = "abc"`：两者都是 3，因为 `"abc"` 恰好连续。

## 5. 顺带：如何同时返回子串内容（不只长度）

更新 maxlen 时记录结束位置与长度：

```python
if dp[j] > maxlen:
    maxlen = dp[j]
    end = i - 1          # s1 中的结尾下标
# 最后：s1[end - maxlen + 1 : end + 1] 即最长公共子串
```

## 6. 易错点

1. 子串版**千万不要写 `max(dp[j], dp[j-1], ...)`**，那会把不连续的也算进来，变成子序列。
2. 必须维护 `maxlen`，否则只 `return dp[n]` 会得到错误结果（最长子串往往不在末尾）。
3. dp[i][j] 含义记错是最大坑：把它当成"前缀最长"就会写出 LCS 的代码；子串一定是"以 (i,j) 结尾"。
4. pre 初值 0、nxtpre 在覆盖前备份——时序与 LCS 一致。
5. 外层 try/except 包裹 input() 是 ACM 多组用例的自然退出写法。
